# my-resources

## 常駐ツール

Webブラウザからいつでもアクセスしたい、またはバックグラウンドで常に動いていてほしいサービスです。これらは比較的軽量か、もしくは「いつでも使えること」に価値があるツールです。

* **navidrome**
* **理由:** 音楽ストリーミングサーバーです。聴きたい時にいつでもスマホやブラウザからアクセスできる必要があるため、常駐（24時間稼働）させるのが一般的です。軽量に動作するため、常駐させても負荷は低いです。


* **netbox**
* **理由:** インフラやネットワークの管理（IPAM/DCIM）ツールです。ネットワーク機器の構成やIPアドレスの割り当て状況は、作業時にいつでも参照・更新したいため、常駐させておくのが望ましいです。



## CLIツール / 必要な時だけ起動するもの

常駐させる必要はなく、作業する時だけコマンドや一時的なコンテナとして立ち上げれば十分なツールです。

* **voicevox**
* **理由:** 音声合成（読み上げ）ツールです。動画編集や音声作成の「作業をする時だけ」起動すればよいため、常駐させる必要はありません。デスクトップアプリ（GUI）や、APIサーバーとして必要な時だけ立ち上げる運用が最適です。


## ディスクを多く食うため使い終わったら消す系

放っておくとストレージ（またはメモリ）を大量に圧迫するため、検証や特定のプロジェクトが終わったらデータごと削除、あるいはクリーンアップを推奨するツールです。

* **tinyllama**
* **理由:** LLM（大規模言語モデル）です。AIモデルのパラメータファイル（GGUFなど）は1つあたり数GBあり、他のモデルも試していくとディスクがすぐに一杯になります。また、実行時には大量のVRAMやメモリを消費するため、ローカルでの実験・使い終わりごとに整理（削除）するのが賢明です。

* **audio-diarization-transcript**
* **理由:** 音声の「話者分離（Diarization）」および「文字起こし（Transcription）」を行うPythonスクリプトやコマンドラインツールです。特定の音声ファイルを処理するタイミングでのみ実行し、処理が終われば削除します。
